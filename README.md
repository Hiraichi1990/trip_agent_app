# trip_agent_app
旅行する際に旅程を提案してくれるエージェントです。全体の旅程を立てるエージェント、地元の観光地やアクティビティを提案するエージェント、訪問先での公用語について教えてくれるエージェント、旅程全体をサマリーするエージェントの4つを協調させ、素敵な旅のプランを提案します。
